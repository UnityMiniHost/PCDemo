PC SDK - 1.0.0

2025-11-12
新版本发布
支持多实例启动游戏。
提供登录、广告对接能力
支持小游戏管理、日志管理、文件系统管理、隐私管理。
支持视图/组件自定义、提供CustomCommand的接口。
提供宿主回调的能力。
适配多种引擎，包括团结、Cocos、Laya、Egret、Unity。

基于 Electron 架构，提供跨平台游戏运行环境。
提供完整的调试工具，包括 vConsole、Inspector、调试菜单。
支持自定义脚本注入，灵活扩展游戏功能。
提供文件系统虚拟化，保障游戏数据安全。
支持多窗口管理，游戏窗口独立控制。
提供完整的生命周期管理，支持启动、暂停、恢复、停止、手动重启。
